# Generador de QR

App vanilla (HTML/CSS/JS) para generar códigos QR de texto o URL.

## Uso
Abrir `index.html` en el navegador.

## Funciones
- Generar QR de texto/URL
- Descargar PNG
- Copiar imagen al portapapeles
- Tema dark/light con persistencia

## Estructura
- `index.html`
- `css/styles.css`
- `js/app.js`
